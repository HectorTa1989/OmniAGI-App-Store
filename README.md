# OmniAGI App Store pages

Static marketing, support, privacy, and terms pages for the OmniAGI iOS App
Store listing. They are intentionally buildless so GitHub Pages can publish the
exact reviewed files.

## Publish

The root `.github/workflows/app-store-pages.yml` workflow publishes this folder
from the public `HectorTa1989/OmniAGI` repository. GitHub Pages is enabled by
the workflow on the first successful deployment.

App Store Connect URLs:

- Marketing: `https://hectorta1989.github.io/OmniAGI-App-Store/`
- Support: `https://hectorta1989.github.io/OmniAGI-App-Store/support.html`
- Privacy: `https://hectorta1989.github.io/OmniAGI-App-Store/privacy.html`

Review the privacy page whenever app data practices change.
