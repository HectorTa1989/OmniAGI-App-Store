Getting started

1. Add a model provider

Open Settings, choose a provider profile, then enter the endpoint, model ID, and your own provider API key. Your provider may charge separately for API usage.

2. Start a conversation

Choose a model and copilot, then write or dictate a message. You can attach supported text, PDF, JSON, and image content.

3. Try Beam

Beam asks selected models for independent perspectives. Free includes two selected models. Pro unlocks the full model selection and fusion workflow.

Purchases and restoration

OmniAGI Pro is an auto-renewable monthly subscription billed by Apple. Use Restore purchase in the Pro screen after reinstalling or moving to another device. To cancel or review billing, open iOS Settings, tap your Apple ID, then Subscriptions.

If Apple shows an active subscription but OmniAGI does not unlock it, connect to the internet, tap Restore purchase, and contact support with the approximate purchase time. Do not send payment credentials.

Data and Sync

Chats are stored locally by default. Pro Sync is optional and requires connecting an OmniAGI account. Before deleting the app, export important local conversations or confirm that Sync has completed.

Troubleshooting

A provider request fails

Check the API key, endpoint, model ID, provider quota, and network connection. OmniAGI does not include provider API credits.

Voice or dictation is unavailable

Confirm microphone and speech recognition permission in iOS Settings. Live voice sends audio to the configured provider only after you begin a call.

A file cannot be read

Unlock password-protected PDFs. Scanned PDFs may need to be attached as images. File size and conversation limits protect device stability.
